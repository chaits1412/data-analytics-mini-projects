# Data Analytics Mini Projects

A collection of smaller, self-contained analytics projects — time series forecasting, Power BI dashboards, and predictive modeling — built alongside my main portfolio project, [Quick-Commerce Gap Analysis](https://github.com/chaits1412/Quick-commerce-analytics).

## Projects

### 📈 [ETH-USD Time Series Forecasting](./eth-usd-forecasting)
Benchmarked four forecasting models (SARIMA, Holt's Winter, LSTM, Prophet) on 5 years of Ethereum price data, with `auto_arima` used to select ARIMA parameters. LSTM significantly outperformed the rest (RMSE 135.82 vs. 1031+ for the classical models). *Group project.*

### 📊 [Project Performance & Employee Utilization Dashboard](./project-performance-dashboard)
A Power BI dashboard tracking project health, cost overruns, and employee utilization — recreating internship-style reporting using a Kaggle dataset.

### 🎬 [Cinematic Insights: Movie Trends Dashboard](./movie-trends-dashboard)
A Power BI dashboard analyzing box office revenue, genre performance, and audience ratings across two decades of movies.

### 🏦 [Bank Customer Churn Analysis](./bank-churn-prediction)
Churn analysis of 10,000 bank customers, originally modeled in Python (Decision Tree, Random Forest, XGBoost, Gradient Boost) and visualized in Tableau.
